# AUREA — краткое ТЗ

## О проекте

**AUREA** — демо-лендинг премиальной студии эстетической косметологии в Санкт-Петербурге. Задача — сделать сайт в стиле референсов LUMI Studio (светлая премиум-эстетика, Playfair Display + Manrope, бронзово-кремовая палитра) с онлайн-записью (3 шага, без мастеров).

Все тексты, услуги, цены и отзывы — выдуманные, но реалистичные для сегмента Санкт-Петербурга.

## Стек

- **Astro 4** — SSG, статика, минимум JS
- **Tailwind CSS** — токены темы в `tailwind.config.mjs`
- **vanilla JS** — для интерактива формы записи, маркé и галереи
- **Google Fonts** — Playfair Display + Manrope
- **Vercel** — деплой (статика из `/dist`)

Без бэкенда. Форма записи при submit показывает тост «Спасибо, мы свяжемся в течение 15 минут» и логирует заявку в `console` (легко подключить Formspree/Telegram-бота потом).

## Дизайн-токены

```
--ink:    #2C2C2C  /* основной текст */
--bronze: #8C715B  /* акцент, кнопки, hover */
--sand:   #E9E3DD  /* фоны секций, разделители */
--cream:  #FAF8F5  /* базовый фон страницы */
--white:  #FFFFFF
```

**Типографика:**
- `Playfair Display` — заголовки, курсивные акценты (`italic`)
- `Manrope` — body, UI, навигация
- Hero заголовок: ~120px, курсивные слова через `<em>`

## Структура

### Главная (`/`)
1. Hero — фото во всю ширину + меню + слоган + кнопка «Записаться»
2. Marquee — бегущая строка «ЭКО · НАТУРАЛЬНЫЕ ПРОДУКТЫ · КОМФОРТ · ...»
3. Our goal — крупная цитата с курсивом и мини-иллюстрацией
4. О нас — фото студии + текст основателя + подпись-курсив
5. Услуги — заголовок + мокап телефона + табы категорий + карточки
6. Бренды — круги с лого (Phyto-C, GIGI и т.д.) + текст слева
7. Работы — заголовок + сетка 2x3 фото + кнопка «Записаться»
8. Отзывы — 4 карточки + одно фото в центре
9. Ритуалы ухода — заголовок + 4 карточки шагов
10. CTA («Ready to Glow?» → «Готовы засиять?») — крупный блок с телефоном и кнопкой записи, без формы
11. Футер — адрес, контакты, навигация, соцсети

### Страница записи (`/booking`)
Три шага, прогресс-бар сверху, правая колонка «Ваш заказ» липкая:
1. **Услуги** — список по категориям, чекбоксы, видно цену и длительность
2. **Дата и время** — календарь месяца + слоты (занятые перечёркнуты)
3. **Контакты** — имя, телефон, email (опц.), комментарий (опц.), чекбокс согласия

### Страница услуги (`/services/[slug]`)
По образцу «Rituals Collection CMS» из референсов: hero с фото + описание, блок «О процедуре», этапы «4 шага», блок «Советы специалиста», мини-CTA. Делаем для 2 приоритетных услуг (контурная пластика губ, биоревитализация), остальные ведут на `/booking` с предвыбранной услугой.

### Правовые
- `/privacy` — политика конфиденциальности
- `/terms` — обработка персональных данных

## Что НЕ делаем

- Мобильную адаптацию (только desktop ≥1280px)
- Реальный бэкенд записи
- Личный кабинет / авторизацию
- Мультиязычность
- Блог

## Что откладываем на потом (после согласования макета)

- Генерация изображений (ChatGPT / Nano Banana) — пока плейсхолдеры в фирменных цветах с подписями
- Подключение формы к Telegram-боту / Formspree
- Мобильная версия
- SEO-мета, OG-картинки, sitemap
