# Стек

## Что сейчас

- **HTML** — один файл `index.html` (~2150 строк)
- **CSS** — встроен в `<style>` в head
- **JS** — встроен в `<script>` в конце body, ваниль
- **Шрифты** — Google Fonts: Playfair Display, Cormorant Garamond, Jost
- **Карта** — iframe Яндекс.Карт
- **Картинки** — локальные JPG/PNG в корне проекта

Никаких зависимостей, никакой сборки, никакого Node. Открывается двойным кликом.

## Почему так и остаётся

Это **демо-работа для портфолио**. Два плюса статики, которые важны:
1. Хостится где угодно (Vercel, GitHub Pages, любой S3) без билда
2. Клиент/рецензент открывает один файл и всё работает, без «а где npm install»

Фреймворки (Next, Astro, Vite) сюда не нужны — у страницы нет роутинга, нет
динамики, нет форм с бэком. Форма записи — демо, отправляется в никуда.

## Что можно менять в стеке

- **Разделить `index.html` на отдельные CSS/JS файлы** — ок, это чище,
  но тогда таких файлов немного и без сборщика (просто `<link>` и `<script>`).
- **Добавить лёгкую либу** (например, Swiper для галереи работ) — только если
  даёт заметный выигрыш и грузится с CDN.
- **Переехать на Astro/11ty** — пока **не делаем**. Если в будущем понадобится
  шаблонизация под несколько услуг (не только губы) — тогда обсудим отдельно.

## Что нельзя

- React / Vue / любой SPA-фреймворк для одностраничника
- Tailwind без сборки (CDN-версия для прода не ок)
- Node-рантайм на Vercel (пусть будет статика)
