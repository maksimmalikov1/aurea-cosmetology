# Структура

## index.html — секции

Один файл, разбит на логические секции. Номера строк могут съезжать после правок —
смотри по id через поиск, а не по строке.

| Секция | id | Что внутри |
|---|---|---|
| Header | `#header` | Логотип Aurea, навигация, CTA |
| Hero | `#hero` | H1, подзаголовок, 2 CTA, буллеты, фото `hero.jpg` |
| Pain / Solution | `#pain` | «Узнаёте себя?» — две колонки |
| Страхи | `#fears` | Снятие возражений |
| Процесс | `#process` | Процедура шаг за шагом |
| Препараты | `#preps` | Сертифицированные филлеры |
| **Все услуги** | `#services` | **27 услуг в 5 категориях** (инъекционная, аппаратная, уход, тело, трихология) |
| До/После | `#beforeafter` | 3 работы с ползунком |
| Цитата | `#quote` | Фото врача `doctor.jpg` + цитата |
| Трансформация | `#transformation` | «До Aurea — и после» |
| Цены | `#prices` | Прайс на основную процедуру |
| Реабилитация | `#rehab` | Что делать после |
| FAQ | `#faq` | Аккордеон |
| Отзывы | `#reviews` | Отзывы клиентов |
| Клиника | `#clinic` | Фото пространства |
| Документы | `#docs` | Визуальный trust-блок с 4 карточками |
| Финальный CTA | `#final` | Форма записи **с чекбоксом согласия на ПДн** |
| Карта | `#map` | Яндекс.Карты iframe |
| Footer | `#footer` | Реквизиты + 7 ссылок на правовые документы + предупреждение |

## legal/ — правовые страницы (отдельные HTML)

Каждая страница — standalone, использует общий `_shared.css`, свой `<header>` с логотипом
и «← На главную», `<footer>` с реквизитами.

| Файл | Что это | Закон |
|---|---|---|
| `privacy.html` | Политика обработки персональных данных | 152-ФЗ |
| `consent.html` | Согласие на обработку персональных данных | ст. 9 152-ФЗ |
| `offer.html` | Публичная оферта об оказании платных медуслуг | ст. 437 ГК РФ |
| `terms.html` | Пользовательское соглашение сайта | — |
| `rules.html` | Правила оказания платных медицинских услуг | ПП РФ № 736 |
| `rights.html` | Права и обязанности пациента | 323-ФЗ |
| `license.html` | Информация о медицинской лицензии | 99-ФЗ |
| `_shared.css` | Общая палитра + типографика + layout | — |

Все данные (ИНН, ОГРН, номер лицензии, адрес) — демо, но реалистичные.

## CSS — цветовая система (из `:root`)

```
--bg-primary:   #FAFAF8   светлый фон
--bg-secondary: #F2EDE8   бежевый фон для чередования
--bg-card:      #FFFFFF   карточки
--accent:       #B8967A   основной золотисто-бежевый
--accent-hover: #9E7D63
--text-primary: #1C1C1C   основной текст
--text-secondary:#5C5047  вторичный
--border:       #E8E0D8
```

Шрифты: `Playfair Display` (заголовки) / `Cormorant Garamond` (body) / `Jost` (UI/кнопки).

## Картинки (все в корне)

- `hero.jpg` — фото в hero
- `doctor.jpg` — врач (используется в секции с цитатой)
- `work1-before.jpg` / `work1-after.jpg` — работа 1 для слайдера до/после
- `work2-before.jpg` / `work2-after.jpg` — работа 2
- `work3-before.jpg` / `work3-after.jpg` — работа 3
- `work1.jpg` / `work2.jpg` / `work3.png` — **не используются в HTML**,
  похоже, оригиналы/альтернативы. Решить потом: удалить или использовать.
