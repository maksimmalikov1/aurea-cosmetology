# Деплой

## GitHub

- **Репозиторий:** https://github.com/maksimmalikov1/aurea-cosmetology
- **Ветка по умолчанию:** `main`
- **Как публиковать:** `git push origin main` — Vercel подхватит автоматически.

## Vercel

- **Проект:** `aurea-cosmetology`
- **Прод-URL:** https://aurea-cosmetology.vercel.app/
- **Тип:** статический сайт, без билда, без Node-рантайма.
- **Корень:** репозиторий целиком, `index.html` на верхнем уровне.
- **Конфиг (`vercel.json`):** не нужен — Vercel сам определяет статику.
- **Auto-deploy:** каждый push в `main` → автоматический прод-деплой.

## Локально

Открыть `index.html` двойным кликом в браузере — всё работает.

Если нужен лёгкий dev-сервер (чтобы Яндекс-iframe и шрифты не ругались на `file://`):

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Открыть `http://localhost:8080`.

## Git

```bash
# новые изменения
git add -A
git commit -m "fix(hero): переделал композицию и копирайт"
git push
```

Коммиты пишем по-русски, в стиле conventional: `тип: что сделал`.
Типы: `feat`, `fix`, `refactor`, `style`, `docs`, `chore`.
