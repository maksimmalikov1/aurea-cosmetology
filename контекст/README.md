# Aurea — косметология (демо)

Одностраничный лендинг клиники эстетической косметологии «Aurea» (Москва).
Главная услуга в этой версии: **контурная пластика губ филлерами**.

Это **демонстрационная работа для портфолио** — все данные (имя врача, адрес, телефон,
цены, отзывы, сертификаты) выдуманы. Можно менять любой контент без страха что-то
сломать с «реальным клиентом».

## Что это

Эта работа — моя старая версия лендинга. Делал её, когда уровень был ниже.
Сейчас уровень вырос, и цель — **переписать/дорефакторить** страницу так, чтобы
её не стыдно было показать как кейс.

## Главный принцип рефакторинга

**Не ломать стек.** Остаёмся на статическом HTML + CSS + немного ванильного JS —
один файл или несколько, без сборки, без фреймворков. Это демо-работа, и её главная
ценность в том, что она открывается в один клик и работает везде.

Все улучшения — внутри этого ограничения: вёрстка, типографика, композиция,
анимация, адаптив, доступность, UX-копирайт.
